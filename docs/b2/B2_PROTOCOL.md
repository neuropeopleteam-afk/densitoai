# Б2: протокол проверки решающего слоя (объявлен до запуска, 24.09.2026)

Гипотезы проверяются скриптами `tools/decision_layer_nested.py` (расчёт) и `tools/decision_layer_eval.py`
(метрики и решение). Правила — `tools/decision_rules.py` (одни и те же для харнесса и оценки).

## Разбиение

- Внешний контур: GroupKFold(5, shuffle, random_state = 42 + r), r = 0…19 (20 повторов); одно и то же
  разбиение для всех критериев области. Группы — компоненты связности (исследование, pixel_hash,
  `docs/k5/pixel_hashes.csv`).
- Внутренний контур: GroupKFold(3) на внешнем train. Модели как в `train_stacked.py`: контур A —
  `contour_a_cols` (у sp_pos с `synth_pos_logit`), вариант предобработки К11, контур B — источник К13,
  StandardScaler → LogReg(C = 1, balanced) и StandardScaler → PCA(32) → LogReg(C = 0.1, balanced);
  стэк 0.5/0.5 по рангам. Порог — правило `config.yaml: thresholds_rule` на inner-OOF стэке.
  Скор внешнего test — ранги относительно inner-OOF (как `inference.percentile_rank`).
- Порог, запас и политика (б) выбираются только на внешнем train (inner-OOF); внешний test не участвует.
- Проверка устойчивости: весь расчёт повторяется на уникальных кадрах (один кадр на pixel_hash).

## Метрики (на внешних фолдах, пул по повтору)

F1 по каждому из 5 критериев; macro-F1 области (среднее F1 типов области) и по 5 критериям; бинарная
F1 области (OR флагов против OR меток); ROC-AUC скоров критериев; ROC-AUC `quality_prob` области
(0.5 · any-модель + 0.5 · max скоров, затем согласование с классом, как `consistent_quality_prob`).
Кластерный бутстрап: 2000 ресэмплов исследований (одни и те же веса для обеих областей), статистика —
Δ, усреднённая по 20 повторам; ДИ 90 %.

## (а) Связки рангов на пороге — критерий приёмки

Правило меняет только порог, скоры критериев не меняются, поэтому AUC каждого критерия тождественно
совпадает и правило проекта «ΔAUC ≥ 0.03 в ≥ 70 % повторов» к нему неприменимо. Меняется только
`quality_prob` через согласование с классом — его AUC используется как условие неухудшения.
Принимаем, если выполнены все условия:

- A1: среднее по повторам Δmacro-F1 (5 критериев) > 0 и Δ ≥ 0 не менее чем в 14 из 20 повторов;
- A2: ни в одной области среднее Δmacro-F1 области < −0.01;
- A3: ни в одной области среднее Δ бинарной F1 < −0.01;
- A4: ни в одной области среднее ΔAUC `quality_prob` < −0.005;
- A5: нижняя граница 90 % кластерного ДИ Δmacro-F1 (5 критериев) ≥ −0.01 (порог неухудшения `paired_gate.py`);
- A6: на уникальных кадрах среднее Δmacro-F1 (5 критериев) ≥ 0; иначе выигрыш приписывается клонам и правило не принимается.

`tools/paired_gate.py` прогоняется на уровне области (score = `quality_prob`, pred = класс) и по
критериям (score одинаковый, pred = флаги); его условие ΔAUC > 0 для пороговой правки не является
критерием, берётся компонента macro-F1 (нижняя граница ≥ −0.01).

## (б) Одно нарушение на строку — критерий приёмки

Политика на область: tau ∈ {выкл, 0.05, 0.1, 0.2, 0.3, 0.5, inf} (второй тип сохраняется, если его
относительный запас ≥ tau). На каждом внешнем фолде выбирается tau с максимальной macro-F1 области
на inner-OOF внешнего train (флаги по порогам этого фолда); при равенстве — ближайшая к «выкл».
Считается поверх базового порога и поверх (а).

- B1: хотя бы для одной области нижняя граница 90 % кластерного ДИ Δmacro-F1 области > 0;
- B2: ни в одной области среднее Δmacro-F1 < −0.01;
- B3: бинарная F1, `quality_class` и `quality_prob` не меняются — проверяется тождеством OR флагов по всем строкам и повторам;
- B4: гипотеза отвергается, если «выкл» выбрано не менее чем в 50 % фолдов в обеих областях;
- B5: на уникальных кадрах для принятой области среднее Δmacro-F1 > 0; иначе выигрыш приписывается клонам.

Включение по области — только для областей, прошедших B1 и B5; бедро по умолчанию выключено.
