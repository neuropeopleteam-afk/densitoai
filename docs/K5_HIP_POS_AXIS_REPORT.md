## 4. sp_axis: ось по центрам тел позвонков — НЕ ПРИНЯТО
`axis_features.py` (модуль): столб позвоночника = строки маски с шириной 0.5..1.6 медианы (отсекает рёбра/гребни таза), диски = минимумы профиля яркости вдоль оси (шаг >= 22 мм), тела = отрезки 15..45 мм; `axis_bodies_deg` = угол линии через центры верхнего и нижнего полных тел, `axis_col_deg` = линейная аппроксимация центроидов только по столбу, `tilt_local_max/mean_deg`, `tilt_step_max_deg`, `n_bodies` (медиана 6, 166 снимков; `docs/k5/axis_features_spine.csv`). Текущий `axis_angle_deg` = линейная аппроксимация центроидов всех строк маски (geometry_features.spine_axis_features), в маску попадают рёбра и таз.
OOF AUC (geom logreg, GroupKFold 5x10, `docs/k5/axis_oof_auc.csv`): axis_angle_deg 0.835 (сырой признак 0.850); axis_bodies_deg 0.628 (0.690); axis_col_deg 0.735 (0.790); tilt_local_max 0.600; tilt_local_mean 0.579; tilt_step_max 0.549; old + axis_col 0.781; old + все новые 0.737. Nested (`docs/k5/nested_axis_sp_axis_decisions.csv`): plus_bodies dAUC -0.048 (0/10), plus_col -0.035 (0/10), plus_bodies_tiltmax -0.085, plus_all -0.069; macro-F1 0.532 -> 0.469..0.536. Ни один вариант не принят.
Интерпретация: разметчик оценивает наклон всего скана (совпадает с аппроксимацией по всей маске), а не ось L1-L4; ось по телам «исправляет» два ложных срабатывания старого признака (6.47 -> 0.23 и 5.64 -> 2.42 град., sp_axis=0), но теряет часть позитивов (2.88 -> 0.34, 2.67 -> 0.87). 17 позитивов с углами: `docs/k5/axis_positives_table.csv` (+ 6 негативов с наибольшим старым углом), миниатюры с осью: `docs/k5/img/sp_axis_positives_axis.png` (внутренние).
