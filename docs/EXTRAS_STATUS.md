## 1. К8 — белые линии (сделано, только флаг)

Источник: `out/WHITE_LINES_AUDIT.md`.

- В экспорте организаторов графики ROI нет: сырой максимум пикселя 252 во всех 499 файлах (уровня 255 нет), после `normalize_pixels` доля ≥ 254 ≈ 1 % по построению (медиана 1.06 %) — кортикальный слой. Визуально проверены 24 кадра — оверлея нет.
- Детектор `extras.white_lines(img_u8)`: пиксели ≥ 254, гор./верт. отрезки ≥ 20 px, толщина ≤ 3 px, контраст с ОБЕИХ сторон ≥ 100 (без контраста детектор ловит кортикальные гребни: 446/499). Срабатывания на 499: **2/499 (0.4 %)** — кадры #40/#45 (край ножки эндопротеза, 2 отрезка, 57 px). По областям: spine 0/166, right_hip 2/172, left_hip 0/161. На внешних DEXA-Osteo с реальной ROI-графикой (нативное разрешение): 13/24.
- Таблица «линии × метка»: рабочий детектор — все ячейки «линии» нулевые, p (Фишер) = 1.0, OR не определён. Наивный детектор: sp_axis OR 0.35 (0.13–0.96), p = 0.051; прочие p ≥ 0.84.
- AUC метки по признакам линий (LogReg, GroupKFold по study, 5 фолдов): sp_pos 0.574, sp_axis 0.477, sp_art 0.408, hip_pos_c 0.614, hip_roi_c 0.843. Последнее объясняется анатомией (длина насыщенного гребня диафиза: 136 px при нарушении против 333 px при норме; r = 0.64 со scan_length_mm), то есть тем же сигналом, что уже есть в контуре A.
- Решение: доля кадров с линиями 0.4 % < 30 % → **только флаг** `white_lines_flag` (в `results_extras.csv`, не в 9 колонках). **Инпейнтинг не делаем**: ассоциации с метками нет, нечего устранять и невозможно проверить OOF без потерь.

## 2. К9 — OOD-gate (сделано)

Источник: `out/OOD_GATE_REPORT.md`, `ood_gate.py`.

- (а) Fingerprint на 499: Manufacturer `GE Healthcare` 499, ManufacturerModelName `Lunar Prodigy Advance` 499, Modality `CR` 499, BitsStored 8 (499), MONOCHROME2 (499), SamplesPerPixel 1 (499), Columns 280×331 / 300×166 / 248×2, Rows 180–405 (после расширения диапазона Rows до 150–450 — все **499/499 `ok`**; первый вариант 200–400 отбраковывал 3 своих файла с Rows 180/401/405). Отсутствующие текстовые теги → `incomplete` (не флаг), противоречие → `mismatch` → `ood_flag`.
- (б) Mahalanobis. Вариант ТЗ (StandardScaler → PCA k=32 → Ledoit-Wolf → T²): порог 7.62, OOF FPR 1.0 %, но внешние PNG отбраковывает лишь **63/130 (48 %)** (arak 46 %, dexa_osteo 26 %, fracatlas 90 %); k = 16/24/64 — 41/57/111 из 130. Причина: среди 499 эмбеддингов только 252 уникальных, PCA переобучается на обучающие точки, OOD-энергия уходит в остаточное подпространство. **Принят** вариант Ledoit-Wolf в полном 1280-d пространстве (усадка 0.03): порог **186.71**, OOF FPR **1.0 % (5/499)**, внешние **130/130 (100 %)** по одним пикселям (медиана расстояния 353 против 90 у своих OOF). Оговорка: статистика выбрана после просмотра внешних результатов среди 4 заранее заданных кандидатов с OOF-порогами (T² PCA, остаточная Q, полное LW, 1-NN); FPR-гарантия от выбора не зависит, оценка 100 % слегка оптимистична.
- (в) Экспозиция: 5 признаков (доля тела, p05/p50/p95 тела, шум лапласианом), пороги 0.5 %/99.5 % квантили; фактическая доля вне диапазона на OOF 6.8 % (34/499) — поэтому флаг **мягкий** (только в `ood_reason`, не в `ood_flag`). Внутри пайплайна на 499: 16 срабатываний (in-sample).
- Итоговое правило `ood_flag = fingerprint mismatch OR LW > 186.71`. Для PNG без тегов честно считается «только по пикселям» (100 %); компонент fingerprint по размерам (Rows/Columns) для PNG: 130/130 вне диапазона GE.
- Искажения `tests/robustness_suite.py` на 30 своих кадрах из 12 удержанных исследований (гейт переобучен без них, порог 182.81): identity **2/30** — оба кадры протеза #40/#45 (LW 300), остальные 28 проходят; гамма 0.7 — 2/30; гамма 1.4 — 2/30; шум σ = 3 % — **5/30** (медиана LW 105 → 156; +#75, #79, #77); resize ×0.8/×1.25 — 30/30 через fingerprint (Columns 224/350 не из {300, 280, 248}), по пикселям 2/30; теги удалены — статус `incomplete`, 2/30. Обсуждение: гейт устойчив к гамме, чувствителен к сильному шуму (3 % от диапазона на 8-битном кадре — заметный сдвиг текстуры), resize честно ловится по тегам.
- Внутри пайплайна на 499 (in-sample, финальная модель): `ood_flag` 0/499, медиана LW 15.6 (in-sample расстояния не показательны, гарантия — OOF).

## 3. Эндопротез (частично)

Первые пороги (площадь 150, полутолщина 4) давали 50/333 срабатываний — кортикальные гребни и плотная кость вертлужной области (`(внутренние миниатюры) endo_top12_hips.png`); после установки порогов между максимумом нормы и протезом — **2/333 срабатывания, оба реальные, ложных 0**.
- Реальных протезов в данных 2 исследования: #82/#83 (ловится) и #40/#45 (не ловится: GE рендерит металл тёмным кольцом с фрагментированной яркой сердцевиной — полутолщина 6.6 px, протяжённость 15 строк; `(внутренние миниатюры) endo_missed_40_45.png`). Добавлять вторую сигнатуру под один пример — переобучение, не делаем. Этот кадр ловит OOD-gate (LW 300 > 183 на hold-out) и детектор белых линий (2 отрезка на краю ножки).
- Честно: правило валидировано на 1 положительном исследовании, чувствительность 1/2 по исследованиям, специфичность 331/331 на 499. Квантиль 99.5 % на бёдрах (полутолщина 17.6 px, площадь 4108 px) — тоже проходил бы только #82/#83.
