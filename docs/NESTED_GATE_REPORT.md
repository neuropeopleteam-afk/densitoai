# Nested-валидация вентильного стэкинга (К2) — полный отчёт

Скрипт: `work/B/nested_gate.py`; данные: `densito_rebuild/data/geometry_features.csv`, `embeddings.npy`, `embeddings_densito.npy` (sp_pos). Запуск 19.09.2026, 10 повторов, 148 с (OMP_NUM_THREADS=1). Лог: `results/nested_gate_log.txt`.

## Протокол

- Внешний контур: GroupKFold, 5 фолдов × 10 повторов, `shuffle=True, random_state=42+r`. Замечание: перестановка строк, как в `train_stacked.py`, разбиение GroupKFold не меняет (группы раскладываются по размеру) — 5 «повторов» там фактически одинаковы; здесь используется настоящий шаффл групп (sklearn 1.9.1).
- Группы: компоненты связности графа (study, pixel_hash), sha1 нормализованных пикселей (`inference.normalize_pixels`). Файлов 499, уникальных изображений 252, групп дубликатов 127, файлов в них 374; групп, объединяющих разные исследования, — 0, т.е. группа = исследование (99 групп для позвоночника, 79 для бедра). Размеры групп дубликатов: 2 файла — 71 группа, 3 — 20, 4 — 22, 5 — 11, 9 — 1, 10 — 2 (`results/pixel_hashes.csv`).
- Внутренний контур: GroupKFold 3 фолда на внешнем train; модели ровно как в `train_stacked.py` (geom: StandardScaler→LogReg C=1 balanced; emb: StandardScaler→PCA32→LogReg C=0.1 balanced; PCA только на train-части). Медианы для импутации — по внешнему train.
- Выбор w_geom ∈ {0, 0.25, 0.5, 0.75, 1} по AUC стэка на inner-OOF (ранги pct внутри inner-OOF); при равенстве — ближайший к 0.5. Порог — на inner-OOF стэке по правилу `train_stacked` (F1-опт при ≥15 позитивов в train, иначе prevalence).
- Внешний test: модели, обученные на всём внешнем train; ранги — относительно inner-OOF-референса (`inference.percentile_rank`); стэк = w·rank_geom + (1−w)·rank_emb; база — w=0.5 с порогом, подобранным тем же способом.
- Метрики: AUC и macro-F1 по каждому повтору (outer-OOF на всех строках); итог — outer-OOF скор, усреднённый по повторам (AUC), и голосование предсказаний по повторам (F1); ДИ — бутстрап по исследованиям (1000).
- Приёмка: прирост AUC ≥ 0.03 в ≥ 7 из 10 повторов И средняя macro-F1 вентиля не ниже базы.
